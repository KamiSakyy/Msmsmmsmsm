# Tsuyu — сквозной мессенджер (Android)

Нативное Android-приложение на Java. Сквозное шифрование **Double Ratchet + X3DH**
(как в Signal), вся передача данных — только через **Firebase Realtime Database**.

## Скачать APK

Последний релиз: **[Releases](../../releases/latest)** → `Tsuyu.apk`
Сборка автоматическая: GitHub Actions (Android SDK 34, JDK 17), подписанный release-APK.

## Шифрование

| Слой | Алгоритм |
|---|---|
| Обмен ключами | X3DH (X25519), без онлайна собеседника |
| Сессия | Double Ratchet (DH-ratchet + symmetric ratchet) |
| Сообщения | AES-256-GCM, канонический AAD |
| Подписи | Ed25519 |
| KDF | HKDF-SHA256 |

* Приватные ключи генерируются на устройстве и **никогда** не уходят в сеть.
* Публичный bundle (ik/ed/spk/spkSig) + ephemeral-ключ идут **с каждым сообщением**,
  поэтому первое сообщение незнакомому/офлайн-собеседнику расшифровывается сразу.
* Пропуск и переупорядочивание сообщений поддержаны (skipped message keys, до 1000).
* Смена приватного ключа — старые чаты остаются читаемыми (архив signed pre-key).
* Экспорт/импорт ключей — для входа на новом телефоне.

### Шифрование профилей
Поля профиля (имя, описание, аватар) запечатаны AES-256-GCM на ключе
`HKDF(APP_DOMAIN_SECRET, salt=uid)`. Секрет домена есть только в клиенте, поэтому
дамп базы — это шифротекст, но любой клиент Tsuyu покажет профиль без обмена ключами.
Каждый профиль подписан Ed25519 владельца — подделка исключена.

## Функционал

* Регистрация/вход: почта + пароль (Firebase Auth), уникальный `@юз`, аватар, описание
* Поиск по `@юзу` в реальном времени с анимацией
* Текст, фото, видео, **коллажи**, голосовые (динамическая волна), кружочки, музыка — всё Base64 через RTDB
* Точные realtime-статусы: в сети / печатает / был(а) в сети
* Реакции двойным тапом (сердечко с наложенными аватарками), меню сообщения (3 точки):
  реакция, ответить, редактировать, переслать, удалить (в т.ч. у обоих)
* Просмотр фото с зумом двумя пальцами, свой видеоплеер, скачивание
* P2P аудио/видео звонки (WebRTC), сигналинг через RTDB
* Мгновенные уведомления через foreground-сервис, ответ прямо из шторки
* Свой звук уведомления (любой mp3) либо встроенный, можно отключить
* Кастомизация: свой шрифт, размер, стиль, свои слова статусов
* Приватность: кто может писать / видеть заход / аватар / «о себе» + публичное фото
* Режим призрака

